# 🎓 COMPLETE LIST OF ACADEMIC PLATFORMS

## 📊 CITATION & PUBLICATION DATABASES

### 1. **Google Scholar**
- **URL:** https://scholar.google.com
- **What it syncs:** Publications, citations, h-index, i10-index, co-authors
- **API:** No official API (use web scraping or Serpapi)
- **Free:** Yes
- **Priority:** ⭐⭐⭐ HIGHEST

### 2. **ORCID** (Open Researcher and Contributor ID)
- **URL:** https://orcid.org
- **What it syncs:** Publications with DOI, education, employment, funding
- **API:** https://pub.orcid.org/v3.0/
- **Free:** Yes
- **Priority:** ⭐⭐⭐ HIGHEST

### 3. **Scopus** (Elsevier)
- **URL:** https://www.scopus.com
- **What it syncs:** Publications, citations, author metrics, journal rankings
- **API:** Scopus API (requires institutional access or paid subscription)
- **Free:** No (requires subscription)
- **Priority:** ⭐⭐ HIGH

### 4. **Web of Science** (Clarivate)
- **URL:** https://www.webofscience.com
- **What it syncs:** Publications, citations, impact factor, research areas
- **API:** WOS API (requires institutional access)
- **Free:** No (requires subscription)
- **Priority:** ⭐⭐ HIGH

### 5. **PubMed / PubMed Central**

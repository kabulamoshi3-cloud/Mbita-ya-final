# Deployment Guide - Mbita Emmanuel Website

## Quick Deploy to Render

### Prerequisites
- GitHub repository: https://github.com/masalagosimon442-dotcom/Mbita-emmanuel
- Render account: https://render.com

### Step 1: Deploy via Blueprint
1. Go to [Render Dashboard](https://dashboard.render.com)
2. Click **"New +"** → **"Blueprint"**
3. Connect your GitHub account
4. Select the `Mbita-emmanuel` repository
5. Render will detect `render.yaml` and auto-deploy

### Step 2: Set Environment Variables
After deployment, add these in your web service settings:

**Required:**
```
DATABASE_URL=<auto-connected>
SESSION_SECRET=<auto-generated>
NEXT_PUBLIC_BASE_URL=https://your-app.onrender.com
PROFESSOR_EMAIL=your-email@example.com
```

**Email (Optional but Recommended):**
```
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-email@gmail.com
SMTP_PASS=your-app-password
```

**Optional Features:**
```
OPENAI_API_KEY=<for AI assistant>
STRIPE_SECRET_KEY=<for payments>
ORCID_ID=<your ORCID>
```

### Step 3: Initialize Database
From Render Shell (in your service dashboard):
```bash
npx prisma db push
npx prisma db seed
```

### Step 4: First Login
- URL: `https://your-app.onrender.com/login`
- Email: `admin@example.com`
- Password: `admin123`
- **⚠️ Change password immediately!**

## Troubleshooting

**Build Fails?**
- Check DATABASE_URL is connected
- Ensure all required env vars are set

**Database Connection Error?**
- Verify PostgreSQL service is running
- Check DATABASE_URL format

**Cold Starts (Free Tier)?**
- Expected on free plan
- Service spins down after 15 min inactivity
- First request takes 30-60 seconds
